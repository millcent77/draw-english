# 小小画家 · Draw & Say

HTML5、CSS3 和原生 JavaScript，无需安装依赖。双击 `启动学习.cmd`，或在项目目录执行 `node serve.cjs`，访问 http://127.0.0.1:8765。麦克风识别请使用 localhost 或 HTTPS，并允许麦克风权限。

## 学习流程

1. 首次选择小橘猫、小奶狗、小白兔或小熊猫。
2. 绘画完成点击 Done，默认正常语速朗读单词，字母固定正常语速（间隔 0.1 秒），最后再读完整单词。可选很慢、慢速、正常速度。
3. 朗读成功结束后点击“开始跟读”，用英语说出完整单词。
4. 输入框可随时用键盘输入单词，麦克风失败也不锁定（忽略大小写和首尾空格）。两项通过按难度奖励：入门 10 星、进阶 15 星、挑战 20 星，同一关完成过程只发一次。
5. 星星购买食物，购买即喂养：饼干 5 星/5 成长，鲜果餐 10 星/12 成长，大餐 20 星/25 成长。每 30 成长提升一级，余额不足无法购买。
6. 点击下一关继续，Apple → Cat → Sun → Tree 循环练习。

## 保存与识别限制

宠物、积分、成长和当前关卡使用 localStorage 保存，仅属于当前浏览器及网址，没有账号或云同步。未完成跟读和绘画不保存。清理浏览器数据会清除存档；存储不可用时提示并在内存中继续。本地积分适合家庭练习，不是服务器防作弊系统。

语音合成优先 en-US，声音由设备提供。跟读使用 SpeechRecognition/webkitSpeechRecognition，核对的是识别出的单词，并非专业发音评分。识别不支持、麦克风拒绝、无声音或网络错误时可重试，不会自动判对或奖励。此 API 支持范围有限，某些浏览器通过在线服务处理声音，页面提示家长；本应用不保存录音。实际麦克风、口音识别和声音质量需要在目标设备验证。

宠物为本地 CSS 立体卡通形象（渐变阴影及身体部件动画），未连接参考网站账号、未导入其宠物资源。修改 app.js 的 pets、foods、levels 可扩展形象、食物和单词。

画布 600 × 400，支持鼠标、触摸、触控笔，四种粗画笔和橡皮擦。SVG 线框位于画布下方，清空和擦除不会影响提示。支持减少动画的系统设置。在线 Nunito 字体不可用时使用本地字体。

## 验证

执行 `node --check app.js` 和 `node tests/flow.test.cjs`。流程测试模拟语音服务，检查逐字母播放、听读写门槛、错误重试、重复领奖、积分不足、喂养、切换关卡、存档恢复、权限拒绝及不支持识别。

直接打开文件时禁用跟读并显示本地网址入口，避免反复的文件权限询问。首次授权请选择“访问该网站时允许”；权限由浏览器管理。开始收音前等待授权，开始收音后有 20 秒完成跟读；显示收音与声音识别状态，支持停止重试。在线识别服务不可用时提示原因，不发放跟读积分。

## 麦克风排查

“检查麦克风”可以授权并显示收音音量，测试十秒后自动关闭，也可手动停止。允许权限后可选择收音设备。音量信号只用于排查收音，不作为单词正确依据，也不保存或上传测试录音。

跟读先通过 getUserMedia 获取所选麦克风，支持音轨输入的浏览器使用该音轨识别；较旧浏览器可能仍使用系统默认麦克风，需在系统或浏览器里调整默认设备。改用连续监听和实时中间结果，只有最终结果匹配才判对。检测到说话但未返回结果时不会误称孩子没有读。麦克风和音量分析资源在结束、错误、取消及超时后释放。

## 分级英语与数学

页面上方可选择英语/数学及入门、进阶、挑战；新设置与各课程位置单独保存，不覆盖原有宠物存档。切换课程会清空当前画板和未完成答案，朗读、收音或庆祝中请先等待结束。

- 英语入门：Apple、Cat、Sun、Tree，提供描画线框。
- 英语进阶：颜色与大小词组，减淡线框。
- 英语挑战：四个完整句子，自由画；跟读和输入需匹配完整句子，输入不带句末标点。逐字母朗读只读字母，跳过空格。
- 数学入门：20 以内加减；进阶：100 以内加减（含进位、退位）；挑战：乘除法（整除）。题目进度与算式分行显示，在画板画数轴、拆分数字或分组，再输入整数答案；正确按难度奖励：入门 10 星、进阶 15 星、挑战 20 星，点击下一题继续。同一轮题目只奖励一次，循环复习可再次获得奖励。

新增课程选择、数学提示和反馈包含中文、英文、泰文，原有页面继续保留中文界面。课程是一组家庭练习题，不是完整学校课程；画作不自动评分，数学只检查输入答案。没有新增依赖或构建步骤，运行 `node --check learning.js` 及原有检查即可；本地服务已支持新的课程脚本。

启动器会显示服务检查和浏览器打开状态，总启动等待约 8 秒。启动失败会显示原因；服务日志为 learning-server.log / learning-server-error.log，不上传 Git。成功后命令窗口自动关闭，后台服务保留，再次启动会复用服务并打开首页。


## 宠物成长和动作

原有存档、喂食价格与每 30 成长提升一级的规则保留。1 级为出生期，2–3 级幼年期，4–6 级成长期，7 级起成熟期；体型、头身比例及成熟期蝴蝶结会变化。眨眼从 1 级可用，招手 2 级、跳跃 4 级、跳舞 7 级解锁，按钮显示锁定等级。喂食会点头和咀嚼，动作不消耗积分。四种宠物分别有不同颜色、耳朵、尾巴和面部特征。采用立体卡通绘制，非可旋转的真实 3D 模型；遵循系统减少动画设置。新增阶段和动作标签包含中英泰三语。

点击或轻触宠物形象（键盘可用 Tab 聚焦后按 Enter/空格）会蹭头、摇尾巴、显示爱心并回应，随后穿插当前等级已解锁的动作。互动不消耗或增加积分、成长值；喂食仍负责成长。英语与数学采用统一难度奖励，按钮提前显示本题星星数，同一题完成过程只发一次奖励。
